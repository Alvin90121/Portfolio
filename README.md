## Featured Cybersecurity Projects

### 1. SOC / SIEM Homelab — Wazuh

**Technologies:** Wazuh, Proxmox VE, Ubuntu Linux, SSH, MITRE ATT&CK

Designed and deployed a virtualised Security Operations Centre (SOC) lab to gain practical experience in security monitoring, alert triage and incident investigation.

**Key activities:**
- Deployed a Wazuh SIEM server on Proxmox VE.
- Configured centralised security monitoring using Wazuh agents.
- Generated controlled security events against a monitored Ubuntu endpoint.
- Investigated failed SSH authentication attempts and brute-force alerts.
- Correlated raw Linux authentication logs with Wazuh alerts.
- Analysed detection rules and MITRE ATT&CK mappings.
- Documented investigation findings, supporting evidence and alert classifications.

**Investigations completed:**
- **Investigation 01:** Invalid SSH Login — Wazuh Rule 5710.
- **Investigation 02:** SSH Brute-Force Detection — Wazuh Rule 5712, MITRE ATT&CK T1110.

These investigations were performed in an authorised, controlled lab environment.

### 2. Vulnerability Assessment Lab — Nessus

**Technologies:** Nessus, Debian Linux, Windows 7, VirtualBox, TCP/IP Networking

Built an isolated virtual network to perform vulnerability discovery and risk assessment as part of university cybersecurity coursework.

**Key activities:**

- Deployed Nessus on a Debian Linux scanning machine.
- Performed network discovery and vulnerability scanning.
- Identified 15 findings, including one Critical and one High severity finding.

- Evaluated vulnerability severity, business impact and potential remediation.
